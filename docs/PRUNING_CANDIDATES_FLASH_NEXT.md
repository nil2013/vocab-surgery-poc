# Flash-Next の追加 pruning 候補（2026-10-07 時点）

Qwen3.8-Flash-Next（MLX 4bit MTP 版 `2b170fa6`）に対する追加 pruning の候補と、それぞれの採否の状態をまとめる。候補の出どころは [残存語彙の調査](REMAINING_VOCABULARY_FLASH_NEXT.md) と、その後に実装した [漢字の静的な判定](DOMAIN.md#漢字の静的な判定) である。どれを採るかはユーザーが決める。この文書は決定ではない。

数値は次の 2 種類から取った。

- **計画による数値**：tool `1afce1a` で plan を作って数えた行数（実機確認）。適用（apply）はしていない。
- **調査による数値**：v2 の残存語彙に対する集計スクリプトの数値（実機確認）。v3 の Greek 削除とは重ならないので、v3 にもそのまま当てはまる。

参照データは kanji-data `0be3577f`、Unihan 17.0.0（ICU4J 78.3 と同じ Unicode 版）、JMdict 2026-10-06 版。

### 簡体字形・繁体字形（`hanForms`）

Unihan で別字の繁体字を持つ字（簡体字形）と、別字の簡体字を持つ字（繁体字・旧字体形）を削る。常用漢字と `子の名に使える漢字` は常に残し、JMdict の見出し語に使われている字を設定した強さで保護する。語彙に現れる候補のうち日本語参照集合の中の字は 1,219 字で、そのうち 832 字は常用・人名用として常に残る。残りの 387 字の扱いが設定で変わる。

| `keepInJMdict` | 追加削減（v3 から） | 削る字（参照集合内） | JMdict で残す字 | 残り行数 |
| --- | ---: | --- | --- | ---: |
| `any`（見出しに一度でも出る字を残す） | 1,274 | 簡体 62 ＋ 繁体 61 | 簡体 64 ＋ 繁体 200 | 178,681 |
| `standard`（非標準表記を除いた見出しに出る字を残す） | 1,818 | 簡体 72 ＋ 繁体 124 | 簡体 54 ＋ 繁体 137 | 178,137 |
| `priority`（よく使われる語に出る字を残す） | 2,811 | 簡体 110 ＋ 繁体 233 | 簡体 16 ＋ 繁体 28 | 177,144 |

**`any` でも削る字**（参照集合内。数字は元の語彙でその字を含む token 数）：

- 簡体字形：`开272 关241 气165 种142 价125 从111 极81 养80 儿75 决66 阳64 范63 适61 帮54 离53 异49 灵37 愿33 宁29 梦25 荣25 盖24 荐23 阴23` ほか
- 繁体字形：`們22 兩16 營11 續10 歡7 輕7 黨7 擔6 獎6 圍5 歐5 舉5` ほか

**`any` では残り、`priority` では削る字**：`any` で JMdict により保護される字のうち、よく使われる語に出ない字。中国語寄りの字が多い。

- 簡体字形（48 字）：`个421 于260 无209 网192 么155 并118 复79 广74 确70 况59 划47 听45 丰33 册29 冲26 烟25 厂23 挂19 坏16 迹16` ほか
- 繁体字形（172 字）：`會53 發36 對32 體31 學27 點25 當24 經23 沒19 關18 麼17 區15 數14 證13` ほか
- `个 无 网` は v2 の `explicitForbidden` ですでに削除されている。

**`priority` でも残る字**：よく使われる語に出る字。日本語で使う字である。

- 簡体字形（16 字）：`侠`（任侠）、`几`（几帳面）、`剥`（剥く）、`嘘`、`姜`（生姜）、`屡`（屡々）、`掴`（掴む）、`洒`（洒落）、`涛`（怒涛）、`疱`（水疱）、`痒`（痒い）、`碍`（無碍）、`葱`、`蝉`、`躯`（体躯）、`麹`
- 繁体字形（28 字）：`佇`（佇む）、`儘`（我儘）、`厭`、`塵`、`夥`、`嬌`（愛嬌）、`屍`、`撥`、`檻`、`爛`（絢爛）、`爺`、`皺`、`籤`、`膠`、`蠣`（牡蠣）、`覗`、`謳`、`贅`（贅沢）、`趨`、`躊`（躊躇）、`鍼`、`鍾`、`鑽`、`闊`、`餃`（餃子）、`騙`、`鬆`、`鯖`

`priority` で残る字は日本語の字、`any` との差分の字は中国語の字、という分かれ方がはっきり出ている。`priority` を基本とし、差分の 220 字を `han-forms.jsonl` で目視確認して、残したい字を `keep` に入れる進め方が、方針（日本語を不便にせず、攻められるところは攻める）に合う（判断）。各字の判定の事実と token の例は、`outputs/runs/flash-next-hanforms-{any,standard,priority}/han-forms.jsonl` にある。

### Latin の他言語（次の候補）

- **ベトナム語固有**：U+1EA0–1EF9 と `ơ ư ă đ`。ほぼベトナム語専用で、`ă` はルーマニア語、`đ` はクロアチア語とも共用する。
- **その他の拡張 Latin**（多い順）：`ı` 386、`ł` 232、`ş` 187、`č` 174、`ą` 172、`ę` 165、`š` 152、`ž` 147、`ż` 145、`ğ` 129、`ś` 126、`ě` 113、`ć` 85、`ř` 82 行。トルコ語・ポーランド語・チェコ語・ルーマニア語の語片が中心。
  - `š ž č ř` は人名に、`ə` は IPA にも使われるので、文字を選んで指定する（判断）。
  - 全 76 字と行数は `outputs/runs/flash-next-ja-en-coding-v2/remaining-analysis/results.json` の `latinOtherCharCounts` にある。

### 保留・未決定のもの

- **部分 UTF-8**：補完すると必ず禁止 Script になる断片は 270 行あり、そのうち Hangul にしかならないものが 259 行。最低限の表現を残すかを含めて保留中。
- **辞書外の中国語の Han 語彙**：JMdict と JMnedict のどちらの漢字表記にも現れない 2 字以上の Han 語。抜き取りでは誤検出は少ないが、日本語でも成立する複合語（`第十六条 公示催告 工程管理`）を含む。削除リストを作るなら、分解できない 15,727 行に絞るか、目視で絞る。
- **ASCII の外国語・西欧のアクセント文字**：技術用語（`filename backend docker`）や借用語（`café`）を巻き込むので、許可リストか目視確認が要る。
